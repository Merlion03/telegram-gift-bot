# Прогрессивные сообщения при неправильном вводе кодового слова

## Описание изменений

Реализована система прогрессивных сообщений при неправильном вводе кодового слова. Теперь вместо одного и того же сообщения пользователь получает разные варианты в зависимости от количества попыток.

## Логика работы

### 1-я попытка (мягкое напоминание)
```
Это кодовое слово не из моего словаря. Пожалуйста, проверьте написание и убедитесь, что этот код указан в посте с итогами конкурса.
```
- Кнопка "Назад" — возврат в главное меню

### 2-я попытка (более настойчивое)
```
Кодовое слово всё ещё не подходит. Проверьте, пожалуйста, правильность написания — возможно, есть опечатка. Кодовое слово должно быть указано в посте с итогами конкурса.
```
- Кнопка "Назад" — возврат в главное меню

### 3-я попытка и далее (финальное с помощью)
```
К сожалению, это кодовое слово снова не подошло. Если вы уверены, что вводите правильно, нажмите «Нужна помощь» — мы всё проверим и поможем разобраться.
```
- Кнопка "Назад" — возврат в главное меню
- Кнопка "Нужна помощь" — связь с поддержкой

## Изменённые файлы

### 1. `telegram-bot/constants/messages.py`
Добавлены три новые константы:
- `INVALID_CODE_WORD_ATTEMPT_1` — сообщение для 1-й попытки
- `INVALID_CODE_WORD_ATTEMPT_2` — сообщение для 2-й попытки
- `INVALID_CODE_WORD_ATTEMPT_3_PLUS` — сообщение для 3-й и последующих попыток

Старая константа `INVALID_CODE_WORD` оставлена для обратной совместимости и теперь ссылается на `INVALID_CODE_WORD_ATTEMPT_1`.

### 2. `telegram-bot/constants/__init__.py`
Добавлен экспорт новых констант:
- `INVALID_CODE_WORD_ATTEMPT_1`
- `INVALID_CODE_WORD_ATTEMPT_2`
- `INVALID_CODE_WORD_ATTEMPT_3_PLUS`

### 3. `telegram-bot/handlers/prize_flow_handler.py`
Обновлён метод `handle_code_word_input`:
- Добавлена логика выбора сообщения в зависимости от `invalid_attempts`
- Импортированы новые константы сообщений

## Как редактировать тексты сообщений

Все тексты находятся в файле `telegram-bot/constants/messages.py`:

```python
# Сообщения при неверном кодовом слове (прогрессивные варианты)
INVALID_CODE_WORD_ATTEMPT_1 = "Ваш текст для 1-й попытки"
INVALID_CODE_WORD_ATTEMPT_2 = "Ваш текст для 2-й попытки"
INVALID_CODE_WORD_ATTEMPT_3_PLUS = "Ваш текст для 3-й и последующих попыток"
```

Просто измените текст в кавычках и сохраните файл. Изменения вступят в силу после перезапуска бота.

## Тестирование

Создан тест `telegram-bot/tests/test_progressive_invalid_code_messages.py`, который проверяет:
- Отправку правильного сообщения для каждой попытки
- Появление кнопки "Нужна помощь" после 3-й попытки
- Сохранение финального сообщения для всех попыток после 3-й

Запуск теста:
```bash
venv\Scripts\activate
cd telegram-bot
python -m pytest tests/test_progressive_invalid_code_messages.py -v
```

## Обратная совместимость

Все существующие тесты продолжают работать. Старая константа `INVALID_CODE_WORD` сохранена для обратной совместимости.
