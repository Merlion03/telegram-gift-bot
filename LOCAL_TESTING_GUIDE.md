## 🚀 Быстрый старт (5 минут)

### Шаг 1: Проверка Docker

```bash
# Проверьте, что Docker работает
docker --version
docker compose version

# Должны увидеть версии (например, Docker version 24.0.0)
```

### Шаг 2: Настройка переменных окружения

```bash
# Скопируйте пример файла
cp .env.example .env
```

**Откройте `.env` и заполните минимально необходимые переменные:**

```env
# ОБЯЗАТЕЛЬНО заполнить:
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
SPREADSHEET_ID=1a2b3c4d5e6f7g8h9i0j
NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
NEXTAUTH_SECRET=your-secret-min-32-characters-long
ADMIN_PASSWORD=your-secure-password

# Можно оставить по умолчанию:
WEBAPP_URL=http://localhost:3000
DATABASE_URL=postgresql://postgres:postgres@postgres:5432/telegram_bot
NEXTAUTH_URL=http://localhost:3000
ADMIN_USERNAME=admin
```

### Шаг 3: Подготовка Google Credentials

```bash
# Создайте папку для credentials (если её нет)
mkdir -p credentials

# Поместите файл google-credentials.json в папку credentials/
# Файл должен быть по пути: credentials/google-credentials.json
```

### Шаг 4: Запуск системы

```bash
# Запустите все сервисы
docker compose up -d

# Дождитесь запуска (30-60 секунд)
# Проверьте статус
docker compose ps
```

**Ожидаемый результат:**
```
NAME                STATUS
bot                 Up
nextjs              Up
postgres            Up
```

## 🐛 Что делать при ошибках

### Ошибка: "Port already in use"

```bash
# Найдите процесс на порту 3000
# Windows:
netstat -ano | findstr :3000

# Linux/macOS:
lsof -i :3000

# Остановите Docker и попробуйте снова
docker compose down
docker compose up -d
```

### Ошибка: "Cannot connect to database"

```bash
# Проверьте статус PostgreSQL
docker compose ps postgres

# Перезапустите БД
docker compose restart postgres

# Проверьте логи
docker compose logs postgres
```

### Ошибка: "Google Sheets API error"

```bash
# Проверьте наличие credentials
ls -la credentials/google-credentials.json

# Проверьте логи бота
docker compose logs bot | grep -i google

# Убедитесь, что:
# 1. Google Sheets API включен в Google Cloud Console
# 2. Service Account имеет доступ к таблице
# 3. SPREADSHEET_ID правильный
```

### Ошибка: "Supabase connection failed"

```bash
# Проверьте переменные окружения
docker compose exec nextjs env | grep SUPABASE

# Проверьте логи Next.js
docker compose logs nextjs | grep -i supabase

# Убедитесь, что:
# 1. URL и ключи правильные
# 2. Таблицы созданы в Supabase
# 3. RLS политики настроены
# 4. Realtime включен
```

### Бот не отвечает

```bash
# Проверьте, запущен ли бот
docker compose ps bot

# Проверьте логи
docker compose logs bot | tail -50

# Проверьте BOT_TOKEN
docker compose exec bot env | grep BOT_TOKEN

# Перезапустите бота
docker compose restart bot
```

### Полная перезагрузка системы

```bash
# Остановите все сервисы
docker compose down

# Удалите volumes (ВНИМАНИЕ: удалит данные БД!)
docker compose down -v

# Пересоберите и запустите
docker compose up -d --build

# Проверьте статус
docker compose ps
```
