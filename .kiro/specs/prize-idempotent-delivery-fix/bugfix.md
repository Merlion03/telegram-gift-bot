# Bugfix Requirements Document

## Introduction

Исправление бага в обработке повторных запросов призов в Telegram боте. Текущая система выдает некорректное сообщение "У вас нет доступных призов", если пользователь запрашивает свой приз повторно после того, как уже получил его. Вместо этого система должна работать идемпотентно: при повторном запросе с правильным кодовым словом возвращать тот же промокод (для цифровых призов) или показывать статус заполненной формы (для физических призов).

## Bug Analysis

### Current Behavior (Defect)

1.1 WHEN пользователь уже получил цифровой приз (промокод) и нажимает кнопку "Получить приз" повторно THEN система показывает ошибку "У вас нет доступных призов" вместо повторной выдачи промокода

1.2 WHEN пользователь уже получил цифровой приз и вводит правильное кодовое слово повторно THEN система не позволяет продолжить процесс получения приза

1.3 WHEN метод `check_user_exists` проверяет наличие пользователя THEN он ищет только призы с `claimed_at IS NULL` (неполученные призы), игнорируя уже полученные призы

1.4 WHEN пользователь уже заполнил форму доставки для физического приза и запрашивает приз повторно THEN система показывает ошибку "У вас нет доступных призов" вместо показа статуса заполненной формы

### Expected Behavior (Correct)

2.1 WHEN пользователь уже получил цифровой приз (промокод) и нажимает кнопку "Получить приз" повторно THEN система SHALL проверить наличие пользователя в таблице призов независимо от статуса `claimed_at`

2.2 WHEN пользователь вводит правильное кодовое слово для уже полученного цифрового приза THEN система SHALL идемпотентно вернуть тот же промокод с инструкциями

2.3 WHEN пользователь вводит правильное кодовое слово для физического приза с уже заполненной формой доставки THEN система SHALL показать сообщение "✅ Вы уже заполнили данные для получения приза.\n\nВыберите нужное действие:" с inline клавиатурой содержащей кнопки "◀️ Назад" и "✏️ Изменить данные" (через WebApp)

2.4 WHEN метод `check_user_exists` проверяет наличие пользователя THEN он SHALL искать пользователя в таблице призов независимо от значения `claimed_at`

2.5 WHEN пользователь запрашивает приз повторно с неправильным кодовым словом THEN система SHALL показать сообщение "Кодовое слово введено неверно"

### Unchanged Behavior (Regression Prevention)

3.1 WHEN пользователь запрашивает приз первый раз с правильным кодовым словом THEN система SHALL CONTINUE TO выдавать промокод для цифрового приза или форму доставки для физического приза

3.2 WHEN пользователь отсутствует в таблице призов (не является победителем) THEN система SHALL CONTINUE TO показывать сообщение "У вас нет доступных призов"

3.3 WHEN пользователь вводит неправильное кодовое слово THEN система SHALL CONTINUE TO показывать сообщение "Кодовое слово введено неверно"

3.4 WHEN система устанавливает `claimed_at` для цифрового приза THEN она SHALL CONTINUE TO устанавливать timestamp при первой выдаче промокода

3.5 WHEN система устанавливает `claimed_at` для физического приза THEN она SHALL CONTINUE TO устанавливать timestamp после заполнения формы доставки

3.6 WHEN пользователь не дал GDPR согласие THEN система SHALL CONTINUE TO запрашивать согласие перед запросом кодового слова

3.7 WHEN пользователь вводит кодовое слово для физического приза впервые THEN система SHALL CONTINUE TO показывать форму доставки через WebApp
