# Implementation Plan: Google Sheets Code Word Column

## Overview

Данный план описывает пошаговую реализацию изменения способа чтения кодового слова (code_word) из Google Sheets. Вместо использования названия листа (sheet_name), система будет читать code_word из отдельного столбца B. Реализация включает обновление основной логики синхронизации, создание скрипта миграции данных и полное обновление всех тестов.
