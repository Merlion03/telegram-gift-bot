# План реализации: Разделение полей формы доставки

## Обзор

Данный план описывает пошаговую реализацию разделения составных полей "ФИО" и "Адрес доставки" на отдельные структурированные поля. Реализация включает обновление TypeScript интерфейсов, схем валидации, UI компонентов, API endpoint, Google Sheets клиента и создание comprehensive test suite.

## Примечания

- Каждая задача ссылается на конкретные требования для обеспечения трассируемости
- Checkpoint задачи обеспечивают инкрементальную валидацию прогресса
- Property-тесты валидируют универсальные свойства корректности из документа дизайна
- Unit-тесты валидируют конкретные примеры и интеграционные точки
- Все изменения должны сохранять существующую функциональность формы (телефон, комментарий, обработка ошибок, Telegram-тема)

## Структура Google Sheets

После реализации структура столбцов в Google Sheets будет следующей:

- Столбец E: last_name (Фамилия)
- Столбец F: first_name (Имя)
- Столбец G: patronymic (Отчество)
- Столбец H: city (Город)
- Столбец I: street (Улица)
- Столбец J: house (Дом)
- Столбец K: apartment (Квартира)
- Столбец L: phone (Телефон)
- Столбец M: comment (Комментарий)
- Столбец N: claimed_at (Время получения)

**Важно**: Перед развертыванием необходимо обновить заголовки столбцов в Google Sheets таблице.
