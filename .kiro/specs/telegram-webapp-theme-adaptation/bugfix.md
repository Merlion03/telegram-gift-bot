# Bugfix Requirements Document

## Introduction

Форма доставки в Telegram WebApp (DeliveryForm.tsx) имеет проблемы с видимостью текстовых элементов при использовании светлой и тёмной тем Telegram. Лейблы полей формы не видны на обеих темах, а введённый текст в инпутах плохо различим на тёмной теме. Это критически влияет на пользовательский опыт, так как пользователи не могут понять, какие данные нужно вводить в поля, и не видят введённый текст.

Проблема вызвана неправильным применением CSS переменных Telegram (`--tg-theme-text-color`, `--tg-theme-secondary-bg-color`), которые не обеспечивают достаточный контраст между текстом и фоном в различных темах.

## Bug Analysis

### Current Behavior (Defect)

1.1 WHEN пользователь открывает форму доставки в Telegram с светлой темой THEN лейблы полей (ФИО, Адрес доставки, Номер телефона, Комментарий) не видны или плохо различимы

1.2 WHEN пользователь открывает форму доставки в Telegram с тёмной темой THEN введённый текст в полях ввода плохо видно на тёмном фоне

1.3 WHEN пользователь открывает форму доставки в Telegram с тёмной темой THEN лейблы полей не видны или плохо различимы

1.4 WHEN пользователь пытается заполнить форму на любой теме THEN отсутствие видимости лейблов затрудняет понимание, какие данные требуется ввести

### Expected Behavior (Correct)

2.1 WHEN пользователь открывает форму доставки в Telegram с светлой темой THEN лейблы полей SHALL быть отчётливо видны с тёмным цветом текста на светлом фоне

2.2 WHEN пользователь вводит текст в поля формы на тёмной теме THEN введённый текст SHALL быть отчётливо виден со светлым цветом на тёмном фоне

2.3 WHEN пользователь открывает форму доставки в Telegram с тёмной темой THEN лейблы полей SHALL быть отчётливо видны со светлым цветом текста на тёмном фоне

2.4 WHEN пользователь просматривает placeholder текст в полях ввода THEN placeholder SHALL быть виден, но с меньшим контрастом чем основной текст (используя `--tg-theme-hint-color`)

### Unchanged Behavior (Regression Prevention)

3.1 WHEN пользователь заполняет форму доставки THEN валидация полей SHALL CONTINUE TO работать корректно с теми же правилами

3.2 WHEN пользователь отправляет форму THEN отправка данных на API SHALL CONTINUE TO работать без изменений

3.3 WHEN пользователь вводит некорректные данные THEN сообщения об ошибках валидации SHALL CONTINUE TO отображаться красным цветом

3.4 WHEN пользователь взаимодействует с кнопкой отправки THEN её стилизация и поведение SHALL CONTINUE TO работать без изменений

3.5 WHEN форма находится в состоянии отправки (isSubmitting) THEN поля ввода SHALL CONTINUE TO быть заблокированы

3.6 WHEN пользователь фокусируется на полях ввода THEN эффекты фокуса (focus ring) SHALL CONTINUE TO отображаться корректно
