# Bugfix Requirements Document

## Введение

Исправление бага с кнопкой "Назад" в процессе получения физического приза. Когда пользователь уже заполнил форму доставки и вводит кодовое слово снова, ему показывается сообщение с двумя кнопками: "Назад" и "Изменить данные". При нажатии на кнопку "Назад" система ошибочно отправляет уведомление "Данные отправлены!" и сообщение о готовности к отправке, хотя должна просто вернуть пользователя в главное меню.

Баг влияет на пользовательский опыт, создавая путаницу - пользователь нажимает "Назад" для возврата в меню, но получает уведомления о подтверждении отправки данных.

## Bug Analysis

### Current Behavior (Defect)

1.1 WHEN пользователь уже заполнил форму доставки для физического приза и вводит кодовое слово снова, затем нажимает кнопку "Назад" (callback_data=`confirm_delivery:{prize_id}`) THEN система отправляет всплывающее уведомление "Данные отправлены!"

1.2 WHEN пользователь уже заполнил форму доставки для физического приза и вводит кодовое слово снова, затем нажимает кнопку "Назад" THEN система отправляет сообщение "Отлично, всё готово к отправке! В среднем доставка занимает 2-3 недели. Если в процессе доставки возникнут вопросы, то их можно задать в этом чате."

1.3 WHEN пользователь нажимает кнопку "Назад" THEN метод `handle_confirm_delivery_callback` вызывает `notification_service.send_delivery_notifications`, что приводит к отправке уведомлений

### Expected Behavior (Correct)

2.1 WHEN пользователь уже заполнил форму доставки для физического приза и вводит кодовое слово снова, затем нажимает кнопку "Назад" THEN система SHALL удалить inline-клавиатуру с кнопками "Назад" и "Изменить данные"

2.2 WHEN пользователь нажимает кнопку "Назад" THEN система SHALL показать главное меню с кнопкой "Получить приз"

2.3 WHEN пользователь нажимает кнопку "Назад" THEN система SHALL НЕ отправлять никаких всплывающих уведомлений (callback.answer должен быть пустым или отсутствовать)

2.4 WHEN пользователь нажимает кнопку "Назад" THEN система SHALL НЕ отправлять сообщение о готовности к отправке

2.5 WHEN пользователь нажимает кнопку "Назад" THEN система SHALL НЕ вызывать `notification_service.send_delivery_notifications`

### Unchanged Behavior (Regression Prevention)

3.1 WHEN пользователь нажимает кнопку "Изменить данные" (WebApp кнопка) THEN система SHALL CONTINUE TO открывать форму доставки в WebApp для редактирования данных

3.2 WHEN пользователь впервые вводит правильное кодовое слово для физического приза и форма доставки НЕ заполнена THEN система SHALL CONTINUE TO показывать форму доставки через WebApp

3.3 WHEN пользователь заполняет форму доставки через WebApp и отправляет данные THEN система SHALL CONTINUE TO отправлять уведомление "Данные отправлены!" и сообщение о готовности к отправке

3.4 WHEN пользователь вводит кодовое слово для цифрового приза THEN система SHALL CONTINUE TO работать без изменений

3.5 WHEN пользователь находится в любом другом состоянии процесса получения приза THEN система SHALL CONTINUE TO работать без изменений
