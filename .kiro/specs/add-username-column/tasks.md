# План реализации: Добавление столбца Username

## Обзор

Данный план описывает последовательность задач для добавления нового столбца "Username" в Google Sheets таблицу. Изменения затрагивают три основных компонента: базу данных PostgreSQL, модель Prize, GoogleSheetsService и SyncService. Все индексы столбцов сдвигаются на +1 после столбца Telegram ID.

- Задачи, отмеченные `*`, являются опциональными и могут быть пропущены для быстрого MVP

- Unit-тесты проверяют конкретные примеры и edge cases
