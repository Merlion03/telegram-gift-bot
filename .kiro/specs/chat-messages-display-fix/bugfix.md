# Спецификация исправления багов отображения сообщений в чате

## Введение

Данная спецификация описывает исправление двух критических багов в системе чата между администраторами и пользователями:

1. **Неправильное отображение отправителя**: Сообщения, отправленные администратором, визуально отображаются как сообщения от пользователя (слева, белый фон) вместо сообщений от поддержки (справа, синий фон).

2. **Дублирование разделителей дат после перезагрузки**: После перезагрузки страницы разделители дат (например, "Сегодня") дублируются, и сообщения одной даты попадают в разные группы, нарушая визуальную структуру чата.

Эти баги критически влияют на пользовательский опыт администраторов, затрудняя понимание того, кто отправил сообщение, и нарушая хронологическую структуру переписки.

## Анализ багов

### Текущее поведение (Дефект)

#### Баг 1: Неправильное отображение отправителя

1.1 КОГДА администратор отправляет сообщение через ChatWindow ТОГДА система отображает это сообщение слева с белым фоном (как сообщение от пользователя) вместо справа с синим фоном (как сообщение от поддержки)

1.2 КОГДА администратор отправляет сообщение ТОГДА система не показывает визуальные индикаторы того, что сообщение отправлено администратором (отсутствует выравнивание справа и синий фон)

#### Баг 2: Дублирование разделителей дат

1.3 КОГДА пользователь перезагружает страницу с открытым чатом ТОГДА система создаёт несколько разделителей с одинаковой датой (например, несколько блоков "Сегодня")

1.4 КОГДА сообщения одной даты загружаются после перезагрузки ТОГДА система группирует их в разные визуальные блоки, разделяя одинаковыми заголовками дат

### Ожидаемое поведение (Корректное)

#### Баг 1: Правильное отображение отправителя

2.1 КОГДА администратор отправляет сообщение через ChatWindow ТОГДА система ДОЛЖНА отображать это сообщение справа с синим фоном (bg-blue-600) и белым текстом

2.2 КОГДА администратор отправляет сообщение ТОГДА система ДОЛЖНА визуально отличать его от сообщений пользователя через выравнивание (justify-end) и цветовую схему

2.3 КОГДА сообщение от администратора приходит через WebSocket ТОГДА система ДОЛЖНА корректно определять его как сообщение типа 'from_support' и отображать соответствующим образом

#### Баг 2: Корректная группировка по датам

2.4 КОГДА пользователь перезагружает страницу с открытым чатом ТОГДА система ДОЛЖНА отображать только один разделитель для каждой уникальной даты

2.5 КОГДА сообщения одной даты загружаются из базы данных ТОГДА система ДОЛЖНА группировать их в один визуальный блок под одним заголовком даты

2.6 КОГДА новые сообщения добавляются через WebSocket в течение дня ТОГДА система ДОЛЖНА добавлять их в существующую группу этого дня без создания нового разделителя

### Неизменное поведение (Предотвращение регрессии)

3.1 КОГДА пользователь отправляет сообщение ТОГДА система ДОЛЖНА ПРОДОЛЖАТЬ отображать его слева с белым фоном и тенью

3.2 КОГДА бот отправляет автоматическое сообщение ТОГДА система ДОЛЖНА ПРОДОЛЖАТЬ отображать его с фиолетовым фоном (bg-purple-100) и меткой "🤖 Бот"

3.3 КОГДА сообщения загружаются из базы данных ТОГДА система ДОЛЖНА ПРОДОЛЖАТЬ сортировать их по времени создания (created_at) в порядке возрастания (старые вверху, новые внизу)

3.4 КОГДА новое сообщение приходит через WebSocket ТОГДА система ДОЛЖНА ПРОДОЛЖАТЬ добавлять его в конец списка и выполнять автоскролл к нему

3.5 КОГДА сообщения группируются по датам ТОГДА система ДОЛЖНА ПРОДОЛЖАТЬ использовать форматирование "Сегодня", "Вчера" и "ДД.ММ.ГГГГ" для разделителей

3.6 КОГДА администратор отправляет сообщение ТОГДА система ДОЛЖНА ПРОДОЛЖАТЬ показывать индикаторы доставки (✓ и ✓✓) для сообщений от поддержки

3.7 КОГДА пользователь скроллит вверх для загрузки истории ТОГДА система ДОЛЖНА ПРОДОЛЖАТЬ корректно работать с пагинацией и добавлять старые сообщения в начало списка

## Условие бага и свойства

### Баг 1: Неправильное отображение отправителя

**Функция условия бага:**
```pascal
FUNCTION isBugCondition1(message)
  INPUT: message типа WebSocketMessage
  OUTPUT: boolean
  
  // Баг проявляется, когда сообщение отправлено администратором
  RETURN message.data.sender_type = 'admin'
END FUNCTION
```

**Свойство: Проверка исправления**
```pascal
// Свойство: Сообщения от администратора отображаются корректно
FOR ALL message WHERE isBugCondition1(message) DO
  displayedMessage ← renderMessage'(message)
  ASSERT displayedMessage.alignment = 'right' AND
         displayedMessage.backgroundColor = 'blue-600' AND
         displayedMessage.textColor = 'white' AND
         displayedMessage.messageType = 'from_support'
END FOR
```

**Свойство: Проверка сохранения**
```pascal
// Свойство: Сообщения от пользователей и ботов отображаются без изменений
FOR ALL message WHERE NOT isBugCondition1(message) DO
  ASSERT renderMessage(message) = renderMessage'(message)
END FOR
```

### Баг 2: Дублирование разделителей дат

**Функция условия бага:**
```pascal
FUNCTION isBugCondition2(state)
  INPUT: state типа ChatState (содержит messages и isReloaded)
  OUTPUT: boolean
  
  // Баг проявляется после перезагрузки страницы, когда есть сообщения
  RETURN state.isReloaded = true AND length(state.messages) > 0
END FUNCTION
```

**Свойство: Проверка исправления**
```pascal
// Свойство: Каждая дата имеет только один разделитель
FOR ALL state WHERE isBugCondition2(state) DO
  groups ← groupMessagesByDate'(state.messages)
  dates ← extractDates(groups)
  ASSERT allUnique(dates) AND
         forall date in dates: count(groups, date) = 1
END FOR
```

**Свойство: Проверка сохранения**
```pascal
// Свойство: Группировка работает одинаково до и после исправления для корректных данных
FOR ALL state WHERE NOT isBugCondition2(state) DO
  ASSERT groupMessagesByDate(state.messages) = groupMessagesByDate'(state.messages)
END FOR
```

## Контрпримеры

### Контрпример 1: Сообщение администратора отображается как от пользователя

**Входные данные:**
```typescript
const message = {
  type: 'new_message',
  data: {
    id: 123,
    session_id: 5,
    sender_type: 'admin',
    message_text: 'Здравствуйте, чем могу помочь?',
    created_at: '2024-03-06T15:34:00Z',
    is_read: false
  }
};
```

**Текущее (неправильное) поведение:**
- Сообщение отображается слева (justify-start)
- Фон белый (bg-white)
- Текст серый (text-gray-900)
- Визуально неотличимо от сообщения пользователя

**Ожидаемое (правильное) поведение:**
- Сообщение отображается справа (justify-end)
- Фон синий (bg-blue-600)
- Текст белый (text-white)
- Показывается индикатор доставки (✓✓)

### Контрпример 2: Дублирование разделителя "Сегодня"

**Входные данные:**
```typescript
const messages = [
  { id: 1, created_at: '2024-03-06T10:00:00Z', message_text: 'Сообщение 1' },
  { id: 2, created_at: '2024-03-06T11:00:00Z', message_text: 'Сообщение 2' },
  { id: 3, created_at: '2024-03-06T15:00:00Z', message_text: 'Сообщение 3' },
];
// После перезагрузки страницы
```

**Текущее (неправильное) поведение:**
```
Сегодня
Сообщение 1 (10:00)
Сообщение 2 (11:00)
Сегодня
Сообщение 3 (15:00)
```

**Ожидаемое (правильное) поведение:**
```
Сегодня
Сообщение 1 (10:00)
Сообщение 2 (11:00)
Сообщение 3 (15:00)
```
