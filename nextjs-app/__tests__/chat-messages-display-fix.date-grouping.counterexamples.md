## Описание бага
Функция `groupMessagesByDate` в `ChatWindow.tsx` (строки 363-381) использует последовательное сравнение дат с переменной `currentDate`. Это приводит к созданию дублирующихся групп для одной даты, если сообщения с этой датой разделены сообщениями с другой датой.

## Первопричина
Логика функции:
```typescript
let currentDate = '';
messages.forEach((message) => {
  const messageDate = new Date(message.created_at).toDateString();
  if (messageDate !== currentDate) {
    currentDate = messageDate;
    groups.push({ date: formatDate(message.created_at), messages: [message] });
  } else {
    groups[groups.length - 1].messages.push(message);
  }
});
```

**Проблема**: Функция сравнивает только с `currentDate` (последней обработанной датой), а не проверяет, существует ли уже группа для этой даты в массиве `groups`.

## Влияние на пользователя

### Проблемы UX
1. **Визуальная путаница**: Пользователь видит несколько разделителей "Сегодня", что сбивает с толку
2. **Нарушение хронологии**: Сообщения одного дня разбросаны по разным группам
3. **Сложность навигации**: Трудно понять, где начинаются и заканчиваются сообщения одного дня
4. **Непрофессиональный вид**: Дублирование разделителей выглядит как баг интерфейса

### Когда проявляется
- После перезагрузки страницы с открытым чатом
- При асинхронной загрузке сообщений из разных источников
- При добавлении новых сообщений через WebSocket после загрузки истории
- При неправильной сортировке сообщений на бэкенде

## Рекомендуемое исправление

Использовать `Map` для отслеживания уже созданных групп по дате:

```typescript
const groupMessagesByDate = (messages: SupportMessage[]) => {
  const groupsMap = new Map<string, { date: string; messages: SupportMessage[] }>();
  
  messages.forEach((message) => {
    const messageDate = new Date(message.created_at).toDateString();
    const formattedDate = formatDate(message.created_at);
    
    if (!groupsMap.has(messageDate)) {
      groupsMap.set(messageDate, { date: formattedDate, messages: [] });
    }
    
    groupsMap.get(messageDate)!.messages.push(message);
  });
  
  return Array.from(groupsMap.values());
};
```

### Преимущества исправления
1. **Гарантия уникальности**: `Map` автоматически обеспечивает уникальность ключей (дат)
2. **Эффективность**: O(1) поиск существующей группы вместо последовательного сравнения
3. **Надёжность**: Работает независимо от порядка сообщений
4. **Простота**: Логика становится более понятной и предсказуемой
